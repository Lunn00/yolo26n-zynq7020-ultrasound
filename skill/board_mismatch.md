# C 仿真通过而板端失配的边界定位

## 适用范围与输入

适用于加速器主机仿真正确、板端错误或不稳定。准备固定输入、模型和程序哈希、主机参考、板端可导出的缓冲区、时钟与实现报告。

## 诊断树

1. 先确认同一文件、同一预处理张量、同一参数和同一 bitstream。入口不同则查软件、缓存和地址，不改 PL 算术。
2. 入口相同则比较最早可观察的工作区边界，再比较预测区与后处理。每次仅导出一个更窄的边界，直到找到首差层或首差字节。
3. 首差在 PL 时，分别检验排程/实际时钟、复位、AXI 地址、行对齐、缓存所有权与运行期循环。为每个假设写出相反结果和回退步骤。
4. 修复后用同一输入重做 C 仿真、时序和板测，再扩展到多输入。保留原始日志、完整缓冲区哈希和构件版本。

## 判定

工具脚本 compare_buffers.py 可报告完整哈希与首差偏移；偏移必须结合 dtype、shape、stride 才能解释。一次样例恢复只证明该复现路径，不证明整个数据集正确。

## 失效边界

若板端无法观测边界数据，必须先补最小插桩；只凭屏幕框和单个置信度无法可靠定位算术、总线或后处理。
