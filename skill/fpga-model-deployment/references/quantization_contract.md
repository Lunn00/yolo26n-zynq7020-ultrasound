# INT8 标定与逐层误差定位

## 适用范围与输入

适用于浮点模型正确而定点部署掉点。准备量化格式、标定样本清单、各通道观测范围、scale 与 zero point、参考激活和整数激活。

## 排查方法

1. 明确量化整数范围与实数零的编码方式。对非对称 uint8，先使标定区间包含零，再计算 scale 和 zero point；统计被裁到端点的比例。
2. 检查标定抽样是否覆盖采集组、类别和尺寸分布。保存有序文件清单与哈希，避免文件名字典序造成隐性偏置。
3. 每层完成后立即捕获激活，在相同物理布局下反量化比较。定位第一个误差突增层，区分值域截断、通道轴错误、分组索引和数据覆盖。
4. 先核对原始输出张量，再核对解码后的目标；单看最终检测数无法定位量化错误。

## 输出与验收

输出标定覆盖表、逐层饱和与误差曲线、首失配原因和仅改变一项的复测结果。修复后重新导出所有依赖该量化参数的 blob 与层表，并完成 C 仿真和板端核对。

## 失效边界

不同量化格式的零点规则不同；少量抽样图的正确性不能代表完整验证集。数值误差下降也不自动证明任务指标或板级功能通过。
