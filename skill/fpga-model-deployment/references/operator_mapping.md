# 特殊算子的软硬件落地决策

## 适用范围与输入

适用于网络包含现有加速器无法表达的算子。准备算子图、张量形状、现有内核支持集、参数与中间张量大小、PS/PL 调用成本及器件余量。

## 候选生成

对每个特殊算子同时提出三条路线：扩展 PL 数据通路、在 PS 执行并交换张量、在模型设计或训练阶段替换结构。不要先按 FLOPs 排序；小计算量算子也可能改变通道索引、数据依赖或控制边界。为每条路线列出新增逻辑、DDR 往返、启动次数、预期数值误差和任务指标变化。

## 分级试验与选择

先做单算子参考比对，再估算整网内存与调用成本。PL 路线需完成整网资源和布线；PS 路线需实测张量往返与 cache 维护；结构替换需在同一验证划分报告精度代价。把任务精度、端到端时间、资源和实现风险放在同一决策表，保留被否决方案的证据。只有数值、目标时钟和板测均通过的候选可列为交付。

## 失效边界

孤立算子综合通过不代表整网可布线；数学等价不意味着硬件代价相同；PS 单算子时间也不能代替多次调用的整机时间。
