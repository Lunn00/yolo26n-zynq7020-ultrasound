# 数据集契约与输入尺寸决策

## 适用范围与输入

适用于检测任务换数据集、重做划分或缩小网络输入。准备图像与标签清单、采集主体或序列 ID、类别定义、原始尺寸、训练配置和候选输入尺寸。没有可靠的分组 ID 时，先记录潜在数据泄漏，不把随机图像划分称为独立验证。

## 可复用步骤

1. 对图像与标签做双向集合差；逐行检查类别、坐标范围和框宽高。空标签需由标注规则确认是阴性样本还是漏标。
2. 以采集主体或序列为单位划分，检查训练与验证组的交集；保存划分清单和随机种子。
3. 对每个候选输入尺寸计算原始目标框缩放后的像素宽高，识别可能被降采样抹掉的小目标。
4. 仅在同一数据版本、同一划分和训练预算下比较输入尺寸。模型、增强、阈值和评价脚本保持固定；同时报告定位指标、内存需求与板上时间。

## 决策与输出

交付三份表：标签异常、组划分、受控尺寸比较。若只有一个尺寸完成验证，结论只能是“该尺寸在这些条件下可用”。若目标检出稳定但严格定位指标下降，应检查框误差和小目标子集，而不是只看单一 mAP。audit_dataset.py 可自动完成配对、YOLO 框格式与可选组交叉检查。

## 失效边界

脚本无法判断标注是否医学或业务上正确，也无法从序列 ID 推断患者独立性。跨数据集精度差异不能归因于输入尺寸。
