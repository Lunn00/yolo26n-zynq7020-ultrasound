# 多构件工程的版本身份与复现

## 适用范围与输入

适用于模型、量化参数、HLS/RTL、IP、位流、PS 程序和启动镜像独立构建的项目。准备各构件的生成命令、工具版本、哈希与依赖关系。

## 版本依赖图

从源数据与权重开始，画出导出模型、量化参数、层表、内核编译、IP、Block Design、bitstream、PS 程序和启动包的有向依赖。每条边记录输入哈希、命令、工具版本和输出哈希；文件名只用于定位，不能当作内容身份。

## 发布验证

1. 先用固定测试向量完成数值回归，再保存 HLS/RTL 构建与实现报告。
2. 核对 PS 寄存器映射和内存布局与本次硬件平台一致，打包后再次计算启动镜像哈希。
3. 部署介质上的参数和镜像逐文件与清单比对；修改任一上游构件，沿依赖图重做受影响的验证。
4. 公共仓库保留构建脚本、报告和哈希清单，区分可重建产物与仅作对照的预构建文件。

## 失效边界

哈希证明字节相同，不证明授权、来源合法或功能正确。工具升级、时钟变化和 IP 参数变化都需要重新构建与板测，不能沿用旧报告。
