# 数据、模型与指标契约

**适用范围**：目标检测模型准备在新数据或新输入尺寸上训练，并计划转成固定精度推理。数据来源、成像模态和网络名称都作为输入参数，不写进步骤。

## 使用前填入

数据目录与授权范围；图像 ID、标签 ID、采集主体或组键；原始尺寸；训练/验证列表；模型权重哈希；候选输入尺寸；训练配置；任务最重视的错误类型。缺少组键时记录潜在泄漏，不用随机划分掩盖它。

## 工作流

1. 用 `audit_dataset.py` 检查图像/标签同名关系、格式和组交叉；人工核对空标注是否真实阴性。输出异常清单，不直接修补标签。
2. 固定同一划分、训练预算、增强和评价代码，仅改变一个模型或输入尺寸。把不同数据版本的指标分开呈现。
3. 记录可区分任务风险的指标。检测任务至少同时检查宽松阈值下的检出与严格定位指标；逐图分析漏检、误检和框偏差。
4. 若要替换算子，先核对逐层等价或拟合误差，再比较同划分任务指标、参数量和部署代价。
5. 固定预处理与标定样本清单。逐层检查量化饱和、首失配激活和原始输出头；最后才计算后处理框。

## 完成条件与失效条件

完成条件是有版本化数据清单、同条件实验表、明确的量化/输出张量契约和不能外推的范围。若没有同数据集对照，不得声称某输入尺寸或模型“更准”；若验证集不含阴性，不能报告阴性图误报率；如果参考头和实现头位于不同语义阶段，先修比较方法。领域专用增强需另查成像语义。

各步骤的操作清单见[数据集](../dataset_contract.md)、[领域训练](../domain_training.md)、[结构替换](../model_surgery.md)、[量化](../quantization_contract.md)和[输出语义](../tensor_contract.md)。本工程的验证结果见[证据索引](../evidence_index.md)，不作为其他任务的默认阈值。
