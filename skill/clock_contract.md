# HLS 排程与板级时钟契约

## 适用范围与输入

适用于 HLS IP 导出到 Block Design 后结果不稳定，或修改频率后需要重建。准备实际执行的 HLS 时钟设置、BD 时钟树、约束文件、布线时序报告与重复输入输出。

## 核对流程

1. 从真正导出 IP 的 Tcl 和综合报告读取排程周期，不从脚本文件名推断。
2. 从 BD 与实现报告读取 IP 管脚实际频率、时钟域关系和约束覆盖；检查 WNS、WHS、失败端点与未约束路径。
3. 固定同一输入、参数和程序，重复采集完整输出哈希。若周期契约不一致，按目标频率重新排程、综合和布线，再重复上板验证。
4. 对跨时钟域接口单独检查握手与同步，不能用单一 WNS 概括全部连接。

## 判定与边界

正 WNS 仅说明已约束路径的静态时序满足；不证明数值正确，也不覆盖未约束路径。任何 HLS、IP、BD、约束或工具版本变化都使旧时序与板测证据失效。
