# 预处理方案的配对消融

## 适用范围与输入

适用于滤波、增强或归一化使个例图像看起来更好，需要决定默认预处理。输入是同一组原始图、标注、固定模型和后处理阈值，以及候选预处理输出。

## 配对试验

1. 每张图以原始图作为共同输入，只改变预处理。固定网络输入变换、量化参数、置信度阈值和 NMS。
2. 对每种模式逐图把预测与标注做一对一匹配，记录 TP、FP、FN、框位置变化与处理耗时。
3. 单列“基线失败而候选成功”和“基线成功而候选失败”的图像，检查边缘、噪声和标注，不用平均置信度掩盖反例。
4. 先按预先选定的任务损失函数选择默认档，再报告例外图像；把主机仿真、板端输出和人工观感分别标注。

## 决策与输出

输出逐图配对表、汇总统计、运行代价与默认策略。若 TP/FN 无改善而 FP 或耗时增加，不因个例置信度上升就更改默认档。若数据无阴性图，只能评价已标注目标附近的错误，不能外推无目标场景。

## 失效边界

配对试验依赖同一标注规则和匹配阈值；滤波可能改变模型校准，必要时另做阈值敏感性分析。主机模拟结果不等于板端全量测量。
