# DDR 工作区、AXI 对齐与缓存所有权

## 适用范围与输入

适用于 PS 与 PL 共享 DDR，且存在输出失配、偶发错误或窄张量访问。准备每个缓冲区基址/长度、读写者、层偏移、行步长、AXI 宽度和 cache API 调用。

## 检查步骤

1. 建地址区间表，比较实际末地址与相邻区间，找重叠或越界；记录每个缓冲区当前所有权。
2. 对每层每行计算起点相对总线字节宽度的余数，检查宽指针访问是否跨行、跨字或越界。
3. 分离对齐和非对齐路径。仅在必要位置改用安全访问，对齐路径保留宽传输；一次不同时改模型与缓存策略。
4. PS 写后 PL 读前执行相应 flush，PL 写后 PS 读前执行相应 invalidate；记录精确范围，按输入、工作区、预测区比完整哈希。
5. 修复后测资源、时序和板速，确认正确性补丁没有引入不可接受的吞吐损失。

## 失效边界

不同平台的 cache line、AXI 宽度与对齐行为不同，必须由实际接口定义重算。改成全字节访问可能掩盖错误并显著降低性能。
