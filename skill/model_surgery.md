# 模型结构替换的等价性与代价审计

## 适用范围与输入

适用于为了部署而替换注意力、分组卷积或其他特殊模块。准备原层与新层定义、权重、归一化参数、训练与验证划分和目标硬件成本模型。

## 验证顺序

1. 固定一组输入，只替换单个模块；在推理态比较逐元素输出。显式核对归一化层的统计量、eps、仿射参数与训练状态，不只复制权重字典。
2. 若声称数学等价，写出权重映射和误差容许来源；若需拟合，只用训练图收集原模块输入与输出，验证图不参与优化。
3. 计算新增 MAC、参数、访存和是否能跳过结构性零。再看整网任务指标，至少区分检出与定位精度。
4. 将替换后的结构重新量化、逐层比对并在目标硬件上测资源、时序和端到端时间。

## 决策

输出“局部数值—整网任务—硬件代价”三层对照表。任一层不满足预先定义的容许条件，就回退或重新设计。保留原结构和候选权重哈希，避免下一轮误用旧参数。

## 失效边界

逐层浮点等价不证明 INT8 等价；减少算子种类不必然减少乘加和延迟；单一 mAP 指标可能掩盖定位损失。
