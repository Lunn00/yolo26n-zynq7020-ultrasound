# HLS IP 不返回完成状态的排查

## 适用范围与输入

适用于软件写入启动寄存器后长期等不到完成。准备控制寄存器读数、时钟/复位状态、AXI 事务状态、循环上界表达式和生成 RTL。

## 排查顺序

1. 验证寄存器可读写、地址正确、复位已释放且时钟存在；设置明确超时，避免无限等待掩盖故障。
2. 看 AXI master 是否仍有未完成读写。若停在某地址，核对缓冲区范围、burst 长度和互连；若总线空闲而状态仍运行，检查控制 FSM 和循环退出。
3. 以生成 RTL 中真实寄存器位宽为准，证明计数器可表示所有运行期上界与退出比较值，包括循环 flatten 后的乘积。
4. 修正后覆盖最大形状做 C/RTL 验证，检查重新生成的计数位宽，再上板确认完成状态和输出。

## 决策与失效边界

计数器回绕只是一个候选根因。超时也可能是 DDR 无响应、复位、时钟或中断配置错误；未采集总线与控制状态前不能直接归因。
