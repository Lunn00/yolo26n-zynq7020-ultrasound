# PS—PL 调用与结果状态协议

## 适用范围与输入

适用于 CPU 启动共享内存加速器并在软件中后处理或显示结果。准备寄存器映射、缓冲区表、缓存 API、输入预处理、输出语义、超时策略和界面状态图。

## 调用协议

1. 为每个缓冲区写出分配者、当前所有者、读写方向、长度和缓存状态；参数、输入、工作区、输出和显示帧不可重叠。
2. CPU 完成输入写入后执行规定的缓存维护，再写地址和启动寄存器；用有界等待观察完成或错误状态。
3. 加速器写回后，CPU 在读取前完成缓存失效；先检查原始输出的版本与长度，再做解码、筛选和绘制。
4. 把每次请求绑定输入 ID、预处理模式和模型版本。切换输入或模式时使旧结果失效，只有本次运行完成才将状态置为“可展示”。
5. 分开计时输入准备、加速器等待、后处理与用户完整等待时间；串口打印放在计时边界外。

## 验收

用主机状态机测试覆盖连续请求、取消、失败回退、自动流程被手动操作打断、模式切换与退出、旧结果失效；上板再检查真实寄存器、缓存及显示。记录每个边界的输入与输出哈希、状态转移和异常处理。

## 失效边界

具体 cache API、寄存器布局和触摸处理因平台而异。主机 UI 测试不能证明实体板上的总线、触摸或视频时序正确。
